# Pretendard 폰트

- 기존 프런트(legacy/front/public/fonts, woff2)와 같은 글꼴. WPF는 woff2를 못 읽어 같은 버전의 OTF(1.309)를 넣었다.
- 출처: Pretendard (https://github.com/orioncactus/pretendard), SIL Open Font License 1.1 — 앱에 포함·배포 가능.
- 기존이 실제로 쓰는 굵기만 포함: Regular(400) · Medium(500, 기본) · SemiBold(600) · Bold(700) · ExtraBold(800).
