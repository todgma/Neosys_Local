# 메뉴별 버튼·내부 메뉴 점검 결과 (2026-10-21)

디버그 빌드의 자동 점검(`Neosys.exe --audit 결과.txt [메뉴키]`, `src/Neosys.Local.App/DevAudit.cs`)으로
메뉴 창마다 **버튼·탭·클릭 항목·목록 행 우클릭 메뉴를 모두 눌러 보고**, 눌러서 열린 창(등록창·선택창·부속문서 등)은 그 안의 버튼까지 한 단계 더 눌렀다.

- 데이터: 메뉴마다 5건씩 넣은 점검용 DB 사본(물건 5·고객 5·계약 5·일정 5·메모 5·상담 5·협력업체 5·만기 대상 5·업무일지 5일·보고서 5)
- 메시지 상자·인쇄/파일 창·외부 열기(브라우저)는 띄우지 않고 기록만 — 삭제 등 확인 질문은 "아니오/취소"로 답함
- 운영 서버는 부르지 않음(연결 안 되는 주소로 고정). 서버 기능은 "서버안내"로 분류

(`MenuScenarioTests`, `OtherMenuScenarioTests` — 전체 테스트 85건 통과).

대시보드의 추천목록·미션문구·리뷰이벤트·공지 더보기·공동중개망·쪽지·대량문자·커뮤니티, 물건·고객의 공동중개망 전송은
"네오시스 웹에서 이용" 안내가 나온다(확정된 결정: 서버 기능은 이관 범위 밖).
