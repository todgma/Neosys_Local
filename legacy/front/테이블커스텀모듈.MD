# 테이블 커스텀 모듈

## 개요
모든 메뉴에서 통일된 형태로 사용할 수 있는 커스터마이징 가능한 테이블 컴포넌트입니다.

## 주요 기능
1. **컬럼 순서 변경**: 헤더를 드래그하여 좌우로 이동
2. **컬럼별 정렬**: 오름차순/내림차순 정렬 (sortableColumns 설정 시)
3. **컬럼별 필터**: 실시간 검색 필터링 (filterableColumns 설정 시)
4. **헤더 우클릭 메뉴**: 정렬, 필터, 색상 설정을 한 번에
5. **행 색상**: 행을 우클릭하여 색상 선택
6. **셀 색상**: 개별 셀을 우클릭하여 색상 선택
7. **설정 저장**: '저장' 버튼 클릭 시 브라우저 로컬스토리지에 저장
8. **설정 가이드**: '설정' 버튼으로 사용법 확인

## 사용 방법

```jsx
import CustomizableTable from '../../components/ui/CustomizableTable';

// 1. 컬럼 정의
const tableColumns = [
  { key: 'id', label: 'ID' },
  { key: 'name', label: '이름' },
  { key: 'date', label: '날짜' },
  // ...
];

// 2. 정렬 가능한 컬럼 지정 (옵션)
const sortableColumns = ['id', 'name', 'date'];

// 3. 필터 가능한 컬럼 지정 (옵션)
const filterableColumns = ['name'];

// 4. 셀 렌더링 함수
const renderTableCell = (row, column) => {
  switch (column.key) {
    case 'id':
      return <span className="font-medium">{row.id}</span>;
    case 'name':
      return row.name || '-';
    default:
      return row[column.key] || '-';
  }
};

// 5. 데이터 준비 (고유 id 필수)
const tableData = data.map((item) => ({
  ...item,
  id: item.id, // 고유 ID 필드 필수
}));

// 6. 컴포넌트 사용
<CustomizableTable
  menuId="고유메뉴ID"  // 메뉴마다 다른 ID 사용 (예: "interview", "partners")
  defaultColumns={tableColumns}
  data={tableData}
  isLoading={isLoading}
  renderCell={renderTableCell}
  onRowClick={행클릭핸들러}
  currentPage={currentPage}
  totalPages={totalPages}
  pageSize={pageSize}
  onPageChange={페이지변경핸들러}
  sortableColumns={sortableColumns}  // 정렬 가능한 컬럼 배열
  filterableColumns={filterableColumns}  // 필터 가능한 컬럼 배열
  emptyMessage="데이터 없음 메시지"
/>
```

## Props 설명

| Prop | 타입 | 필수 | 설명 |
|------|------|------|------|
| menuId | string | ✓ | 메뉴 고유 ID (설정 저장 키로 사용) |
| defaultColumns | array | ✓ | 컬럼 정의 배열 `[{ key, label }]` |
| data | array | ✓ | 테이블 데이터 (각 항목은 고유 id 필드 필요) |
| isLoading | boolean | ✓ | 로딩 상태 |
| renderCell | function | ✓ | 셀 렌더링 함수 `(row, column) => ReactNode` |
| onRowClick | function |  | 행 클릭 핸들러 |
| currentPage | number | ✓ | 현재 페이지 번호 |
| totalPages | number | ✓ | 전체 페이지 수 |
| pageSize | number | ✓ | 페이지당 항목 수 |
| onPageChange | function | ✓ | 페이지 변경 핸들러 |
| sortableColumns | array |  | 정렬 가능한 컬럼 key 배열 |
| filterableColumns | array |  | 필터 가능한 컬럼 key 배열 |
| emptyMessage | string |  | 데이터 없을 때 메시지 (기본: "검색 결과가 없습니다") |

## 사용자 인터랙션

### 헤더 우클릭 메뉴
컬럼 헤더를 우클릭하면 다음 옵션들이 표시됩니다:
- **정렬** (sortableColumns에 포함된 경우)
  - 오름차순 정렬
  - 내림차순 정렬
  - 정렬 해제
- **필터** (filterableColumns에 포함된 경우)
  - 검색어 입력
  - 필터 해제
- **헤더 색상**
  - 없음, 파랑, 초록, 노랑, 빨강, 보라, 회색

### 행/셀 우클릭
- **행 우클릭**: 행 전체 색상 선택
- **셀 우클릭**: 개별 셀 색상 선택

## 저장 및 로드

설정은 `table_config_{menuId}` 형태로 localStorage에 저장되며, 다음 내용을 포함합니다:
- 컬럼 순서 및 색상
- 정렬 설정
- 필터 설정
- 행/셀 색상 설정

나중에 DB 연동 시 이 JSON 구조를 그대로 사용할 수 있습니다.
