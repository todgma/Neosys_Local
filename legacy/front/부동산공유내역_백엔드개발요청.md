# 부동산공유내역 백엔드 개발 요청

## 개요
물건 등록/수정 화면(PropertyFormPage.jsx)에 **부동산공유내역** 기능을 추가하기 위해 백엔드 API 개발을 요청합니다.

---

## 화면 구성

### 위치
- PropertyFormPage.jsx 상단의 카드 영역
- 기존: 소유주 | 임차인 | 상담이력 (3개 카드)
- 변경: 소유주 | 임차인 | 상담이역 | **부동산공유내역** (4개 카드, 2x2 그리드)

### UI 구성
소유주 카드와 동일한 형식으로 구성:
- 상단: 제목 + 버튼(+ 추가, 이력보기, 크게보기)
- 테이블: 공유내역 목록 (최대 높이 제한, 스크롤)
- 각 행마다 수정/삭제 가능

## 데이터 구조

### 부동산공유내역 테이블: `PT_SHARE_HISTORY`

| 컬럼명 | 타입 | 설명 | 필수 | 비고 |
|--------|------|------|------|------|
| share_idx | BIGSERIAL | 공유내역 인덱스 (PK) | ✅ | Auto Increment |
| pt_no | BIGINT | 물건번호 (FK) | ✅ | PT_SALE.pt_no 참조 |
| share_date | DATE | 공유일자 | ✅ | |
| share_platform | VARCHAR(50) | 공유플랫폼 | ✅ | 네이버, 다음, 직방, 호갱노노 등 |
| share_status | VARCHAR(20) | 공유상태 | ✅ | ACTIVE(활성), INACTIVE(비활성), EXPIRED(만료) |
| share_url | TEXT | 공유URL | ❌ | 해당 플랫폼 매물 URL |
| share_id | VARCHAR(100) | 공유ID | ❌ | 플랫폼별 매물 ID |
| share_memo | TEXT | 메모 | ❌ | 공유 관련 메모 |
| exposure_start_date | DATE | 노출시작일 | ❌ | |
| exposure_end_date | DATE | 노출종료일 | ❌ | |
| reg_dt | TIMESTAMP | 등록일시 | ✅ | DEFAULT CURRENT_TIMESTAMP |
| reg_id | VARCHAR(50) | 등록자 ID | ✅ | |
| upd_dt | TIMESTAMP | 수정일시 | ❌ | |
| upd_id | VARCHAR(50) | 수정자 ID | ❌ | |

## 데이터베이스 스키마 (PostgreSQL)

```sql
-- 부동산공유내역 테이블 생성
CREATE TABLE pt_share_history (
    share_idx BIGSERIAL PRIMARY KEY,
    pt_no BIGINT NOT NULL,
    share_date DATE NOT NULL,
    share_platform VARCHAR(50) NOT NULL,
    share_status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
    share_url TEXT,
    share_id VARCHAR(100),
    share_memo TEXT,
    exposure_start_date DATE,
    exposure_end_date DATE,
    reg_dt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    reg_id VARCHAR(50) NOT NULL,
    upd_dt TIMESTAMP,
    upd_id VARCHAR(50),
    CONSTRAINT fk_pt_share_history_pt_no FOREIGN KEY (pt_no) REFERENCES pt_sale(pt_no) ON DELETE CASCADE
);

-- 인덱스 생성
CREATE INDEX idx_pt_share_history_pt_no ON pt_share_history(pt_no);
CREATE INDEX idx_pt_share_history_share_date ON pt_share_history(share_date);
CREATE INDEX idx_pt_share_history_share_platform ON pt_share_history(share_platform);

-- 컬럼 코멘트
COMMENT ON TABLE pt_share_history IS '부동산공유내역';
COMMENT ON COLUMN pt_share_history.share_idx IS '공유내역 인덱스 (PK)';
COMMENT ON COLUMN pt_share_history.pt_no IS '물건번호 (FK)';
COMMENT ON COLUMN pt_share_history.share_date IS '공유일자';
COMMENT ON COLUMN pt_share_history.share_platform IS '공유플랫폼';
COMMENT ON COLUMN pt_share_history.share_status IS '공유상태 (ACTIVE/INACTIVE/EXPIRED)';
COMMENT ON COLUMN pt_share_history.share_url IS '공유URL';
COMMENT ON COLUMN pt_share_history.share_id IS '플랫폼별 매물 ID';
COMMENT ON COLUMN pt_share_history.share_memo IS '메모';
COMMENT ON COLUMN pt_share_history.exposure_start_date IS '노출시작일';
COMMENT ON COLUMN pt_share_history.exposure_end_date IS '노출종료일';
COMMENT ON COLUMN pt_share_history.reg_dt IS '등록일시';
COMMENT ON COLUMN pt_share_history.reg_id IS '등록자 ID';
COMMENT ON COLUMN pt_share_history.upd_dt IS '수정일시';
```

## 프론트엔드 연동 예정

### 파일
- `src/pages/properties/PropertyFormPage.jsx` - 부동산공유내역 카드 추가
- `src/services/shareHistoryService.js` - API 호출 서비스 (신규 생성)

### 주요 기능
1. 부동산공유내역 목록 표시 (테이블 형식)
2. 공유내역 추가 (+ 추가 버튼)
3. 공유내역 수정 (인라인 수정)
4. 공유내역 삭제 (× 버튼)
5. 이력보기 (전체 이력 팝업)
6. 크게보기 (새 창으로 확대)

## 참고사항
- 소유주(PT_HOLDER) 테이블과 유사한 구조로 설계
- 물건 삭제 시 공유내역도 함께 삭제 (CASCADE)
- 날짜 형식: YYYY-MM-DD
- 공유플랫폼/상태는 코드값으로 관리 (추후 코드 테이블 추가 가능)
