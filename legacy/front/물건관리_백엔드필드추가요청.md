# 물건 정보 백엔드 필드 추가 요청

## 개요
프론트엔드 UI(PropertyFormPage.jsx)에는 존재하지만 백엔드 DTO(PropertyCreateDto)에 없는 필드들을 추가 요청합니다.

## 추가 필요 필드 목록

### 1. MvnPsbYn (이전가능/즉시입주 여부)
- **필드명**: `MvnPsbYn`
- **타입**: `string?`
- **설명**: 즉시입주 가능 여부
- **값**:
  - `Y`: 가능
  - `N`: 불가
- **UI 위치**:
  - 기본정보 탭 > 예정일/기타 정보 섹션 (라인 1643)
  - 상세정보 탭 > 즉시입주 (라인 1887)

---

### 2. HouseRental (임대주택/전세자금대출 여부)
- **필드명**: `HouseRental`
- **타입**: `string?`
- **설명**: 전세자금대출 가능 여부 또는 임대주택 여부
- **값**:
  - `Y`: 가능/해당
  - `N`: 불가/비해당
- **UI 위치**:
  - 기본정보 탭 > 예정일/기타 정보 섹션 (라인 1650)
  - 상세정보 탭 > 전세자금대출 (라인 1880)

---

### 3. PetYn (반려동물 허용 여부)
- **필드명**: `PetYn`
- **타입**: `string?`
- **설명**: 반려동물 사육 가능 여부
- **값**:
  - `Y`: 가능
  - `N`: 불가
- **UI 위치**:
  - 기본정보 탭 > 예정일/기타 정보 섹션 (라인 1659)
  - 상세정보 탭 > 반려동물 (라인 1870)

---

### 4. Top (탑층 여부)
- **필드명**: `Top`
- **타입**: `string?`
- **설명**: 해당 물건이 탑층인지 여부
- **값**:
  - `Y`: 탑층
  - `N`: 탑층 아님
  - `""`: 선택 안 함
- **UI 위치**:
  - 기본정보 탭 > 예정일/기타 정보 섹션 (라인 1666)

---

### 5. PtMemo (물건 메모)
- **필드명**: `PtMemo`
- **타입**: `string?`
- **설명**: 물건에 대한 자유 형식의 메모/특이사항
- **값**: 자유 텍스트
- **UI 위치**:
  - 기본정보 탭 > 메모 필드 (라인 1418)

---

## API 명세 업데이트 필요

### 1. POST /api/property (등록)
Request Body에 위 5개 필드 추가

### 2. PUT /api/property/{PtNo} (수정)
Request Body에 위 5개 필드 추가

### 3. GET /api/property/GetPropertyList (조회)
Response의 ptSales 배열 항목에 위 5개 필드 추가

### 4. GET /api/property/{PtNo} (상세 조회)
Response data에 위 5개 필드 추가

## 우선순위
- **High**: PtMemo, PetYn, MvnPsbYn (사용자가 자주 입력하는 필드)
- **Medium**: HouseRental, Top

---

## 참고사항
- 현재 프론트엔드에서는 이 필드들을 이미 formData에 포함하여 전송하고 있으나, 백엔드에서 받지 못해 데이터가 유실되고 있습니다.
- 기본값: MvnPsbYn, HouseRental, PetYn은 'N'으로, Top은 빈 문자열로 초기화됩니다.
- 모든 필드는 Nullable(선택사항)로 처리해야 합니다.
